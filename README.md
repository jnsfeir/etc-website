# ETC Lebanon — Expertise Training Center

Official website for **Expertise Training Center (ETC)**, Lebanon's premier Autodesk & Rhino Authorized Training Center. Founded in 2005 by Naji Sfeir. Live at [jnsfeir.github.io/etc-website](https://jnsfeir.github.io/etc-website/).

---

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — hero, stats, services, department preview, CTAs |
| `pages/about.html` | Founder bio, project timeline, corporate clients, instructors |
| `pages/courses.html` | 156+ courses with prices across 8 departments |
| `pages/schedule.html` | 2026 class schedule with location filter (Lebanon / Online / UAE) |
| `pages/kids.html` | ETC for Kids — programs, age groups, pricing |
| `pages/certificates.html` | Career roadmaps and DGTVE-attested certificate programs |
| `pages/contact.html` | Contact info, locations, WhatsApp, FAQ |

## Tech

- Pure HTML / CSS / JavaScript — no frameworks, no build step
- Google Fonts: Outfit + Fraunces
- Scroll reveal via IntersectionObserver
- Responsive with hamburger nav (mobile-first breakpoints)
- Hosted on GitHub Pages
